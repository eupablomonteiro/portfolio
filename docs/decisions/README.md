# Decisões arquiteturais (ADRs)

Registre decisões que outra pessoa precisaria entender para manter o projeto sem quebrar contratos.

Formato: `NNNN-titulo-curto.md`, usando `0000-template.md`.

Uma decisão deve responder:

- o que foi decidido;
- qual contexto forçou a decisão;
- quais alternativas foram consideradas;
- por que a escolhida venceu;
- qual trade-off foi aceito;
- qual consequência isso traz.

Não registre decisões triviais nem converse com o chat como se fosse memória permanente.

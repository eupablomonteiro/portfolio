# Handoffs

Um arquivo por sessão de trabalho: `YYYY-MM-DD-<slug>.md`.

Use o comando `/handoff` para registrar:

- objetivo da sessão;
- o que foi feito;
- arquivos alterados;
- decisões e motivos;
- validações executadas;
- perguntas em aberto;
- próximos passos.

Ao retomar o trabalho, leia o handoff mais recente antes de abrir uma nova frente.
